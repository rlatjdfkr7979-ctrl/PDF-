🔄 페이지 회전

🔖 목차(북마크) 추가

+ 항목 추가로 북마크를 만들고 제목과 페이지 번호를 입력하세요. ▶(들여쓰기)로 하위 항목, ▲▼로 순서를 조정합니다.
대상 PDF에서 ▶ 페이지 보드(합치기 결과)를 고르면 보드 순서대로 합친 PDF에 목차를 넣습니다.
📥 기존 목차 불러오기로 PDF에 이미 있는 북마크를 가져와 편집할 수 있습니다(실행 시 기존 목차는 새 목차로 교체됩니다).

한 줄에 제목,페이지 · 앞 공백 2칸 = 하위 항목. 위 편집기와 자동 동기화됩니다.
